# Barbearia-web
Plataforma SaaS desenvolvida para otimizar agendamentos e o controle financeiro de barbeiros autônomos. O sistema resolve dores críticas do modelo solo, reduzindo no-shows através de alertas via WhatsApp e centralizando indicadores essenciais como faturamento bruto, custo de insumos, lucro líquido e o mix de serviços mais lucrativos para o negócio.
